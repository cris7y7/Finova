# VERSION 2.1 NOVYRA  21/04/2026
Módulo completo de seguridad:

- PIN de 4 dígitos para proteger el acceso
- Cifrado AES-256-GCM de todos los datos en localStorage
- Código de respaldo de 8 dígitos en caso de olvidar el PIN
- Re-cifrado automático al cambiar el PIN
- Descifrado limpio al desactivar el PIN
- Bloqueo automático por 5 minutos de inactividad
- Bloqueo temporal de 1 minuto tras 5 intentos fallidos
- Bloqueo al enviar la app al background
- Validación estricta de importación JSON (esquema, tipos, rangos, sanitización)
- Protección contra CSV Injection al exportar
- Content Security Policy (CSP) contra scripts externos

NOTAS TÉCNICAS:
- Stack: HTML5 + CSS3 Vanilla + JavaScript ES6 (sin frameworks)
- Íconos: Heroicons por Steve Schoger (SVG inline artesanal offline) + Lucide SVG
- Empaquetado: Capacitor 8 para APK nativo de Android
- Almacenamiento: localStorage con Cifrado E2E AES-256-GCM
- Cloud: Google Drive Cloud v3.5 (OAuth 2.0 via System Browser Deep Link)
- IA: Groq API (Llama 3.3 70B + Llama 4 Scout Vision OCR) via Netlify Functions
- Distribución: APK Android + Netlify Web (novyranet.netlify.app)
