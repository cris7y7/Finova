#VERSION 2.1 NOVYRA  21/04/2026
Módulo completo de seguridad:

- PIN de 4 dígitos para proteger el acceso
- Cifrado AES-256-GCM de todos los datos en localStorage
- Código de respaldo de 8 dígitos en caso de olvidar el PIN
- Re-cifrado automático al cambiar el PIN
- Descifrado limpio al desactivar el PIN
- Bloqueo automático por 5 minutos de inactividad
- Bloqueo temporal de 1 minuto tras 5 intentos fallidos
- Bloqueo al enviar la app al background
- Validación estricta de importación JSON (esquema, tipos, rangos, sanitización)
- Protección contra CSV Injection al exportar
- Content Security Policy (CSP) contra scripts externos

NOTAS TÉCNICAS:
- Stack: HTML + CSS + JavaScript vanilla (sin frameworks)
- Empaquetado: Capacitor 8 para Android APK
- Almacenamiento: localStorage con cifrado AES-256-GCM opcional
- Gráficas: Chart.js con paleta personalizada NOVYRA
- Tasas de cambio: Frankfurter API (tiempo real)
- IA: Groq API (Llama 3.3 70B + Llama 4 Scout Vision) via Netlify Functions
- OCR: Llama 4 Scout 17B con soporte de imágenes
- PDF: jsPDF + html2canvas
- Iconos: Lucide Icons
- Seguridad: PIN + AES-256-GCM + CSP + biometría nativa
- Google Drive: OAuth 2.0 con auto-refresh de token
- Hosting: Netlify (web + serverless functions)
- Distribución Android: GitHub Releases
- Compatibilidad: Android 8+, iOS 14+, Chrome, Firefox, Safari
- PWA: instalable en cualquier dispositivo
- URLs: novyranet.netlify.app (landing) · novyranet.netlify.app/app (app)
